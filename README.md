# Master's Thesis: Business Attitudes Toward Corruption at the European Level

## Overview

This repository contains the R code developed for my Master's thesis in Data mining.

The project investigates European companies' attitudes towards corruption using data from the Flash Eurobarometer 524 survey.

The analysis combines several multivariate statistical techniques to identify latent patterns in companies' perceptions of corruption and examine their relationship with business characteristics.

---

## Dataset

**Flash Eurobarometer 524**

Businesses' attitudes towards corruption in the European Union.

The dataset is not included in this repository due to licensing restrictions.

---

## Research Methods

- Data cleaning and preprocessing
- Descriptive statistics
- Latent Class Analysis (LCA)
- Correspondence Analysis (CA)
- Chi-Square Test
- Cramér's V
- Binary Logistic Regression
- Data Visualization using ggplot2
